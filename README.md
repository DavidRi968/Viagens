# ✈️ Agência de Viagens

Landing page responsiva desenvolvida para simular o portal de uma agência de viagens, permitindo que o usuário solicite orçamentos personalizados e explore pacotes promocionais e destinos naturais.

## 🚀 Funcionalidades

- **Formulário de Orçamento:** Campos para dados pessoais, datas de ida e volta, seleção de origem/destino, opção de cama infantil e preferências de hospedagem (piscina, Wi-Fi, garagem e suíte).
- **Vitrine de Ofertas:** Layout em CSS Grid destacando destinos nacionais com até 50% de desconto.
- **Explore a Natureza:** Cards informativos com valores de passagens de ida e volta.
- **Design Responsivo:** Adaptação completa para desktop, tablets e smartphones utilizando Flexbox, CSS Grid e Media Queries.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica (`header`, `main`, `section`, `article`, `figure`, `address`, `nav`, `footer`).
- **CSS3:** Estilização moderna com Flexbox, CSS Grid, tipografia personalizada (Google Fonts - Raleway) e responsividade.
